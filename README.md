# Task Board - Week 4 Project

Build a complete Task Board application from scratch using AI assistance.

## Project Overview

A simple Kanban-style task board with:
- Backend: FastAPI + Python
- Frontend: React (Vite)
- In-memory storage (no database)

## Getting Started

This repo starts nearly empty. Your job is to build it from specifications.

### Specifications

All requirements are in the `specs/` folder:
- `requirements.md` - High-level requirements
- `user-stories.md` - User stories with acceptance criteria
- `api-spec.md` - API endpoint specifications
- `frontend-spec.md` - UI/UX specifications
